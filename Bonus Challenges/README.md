# Bonus Challenges

This folder contains the additional challenges completed as part of the SugarSense Diabetes Risk Screening project.

## Bonus 1
Additional model analysis and challenge results.

## Bonus 2 — Learning Curve
Learning curve analysis to evaluate model performance with increasing training data.

## Bonus 3 — Mini App
A simple patient risk-screening function using the trained model.

The mini app classifies patients into:

- Low Risk
- Medium Risk
- High Risk

The trained model is saved as:

`sugarsense_model.joblib`
